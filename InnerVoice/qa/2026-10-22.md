## Boundaries

Code is not production-tested after deployment until this PR is approved, merged and deployed. Branch UI checks used the real production API, not mocked success data; only error tests intercepted a failing response. Password controller tests mock the database. Existing MySQL integration CI runs separately on this PR.

Not exhaustive: Apple/Google new-account OAuth, every browser/device microphone permission, external music catalogue playback, offline/reconnection, and admin deletion of real accounts were not exercised. No real user notes were edited or deleted. QA accounts/media are cleaned up separately after the run.

No paid plans, schema changes or production code deployment. Pool defaults to 4 connections to fit the current 5-connection DB cap (override with DB_CONNECTION_LIMIT).
